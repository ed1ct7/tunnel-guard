# Legacy

Ранние версии Tunnel Guard. Не поддерживаются, оставлены для истории. Актуальное приложение — в корне репозитория (Tauri + React).

- `scripts/` — первые PowerShell-прототипы kill switch для v2rayN/Mihomo.
- `dotnet/` — версия на .NET (WinForms), предшественник Tauri-приложения. Сборка: `dotnet build` (нужен .NET 10 SDK).
